2 · Plurales
Plurales con Intl.PluralRules
Con t('CLAVE', { count }) se elige CLAVE_zero / _one / _two / _few / _many / _other según la regla del idioma (Intl.PluralRules), y también se entiende la forma ICU {n, plural, one {…} other {…}}. {count} y # se sustituyen por el número con el formato del idioma.
// es-ES/translations.json
"ITEMS_one": "{{count}} artículo",
"ITEMS_other": "{{count}} artículos",
"RESTAN": "{{n, plural, one {# día} other {# días}}}"

// plantilla
p= t('ITEMS', { count: 3 })  → 3 artículos
p= t('ITEMS', { count: 1 })  → 1 artículo
p= t('RESTAN', { n: 5 })  → 5 días
