P-36

Cuando no se puede actualizar sola, y si algo falla

Actualizar dentro de la app funciona con el instalador de Windows y en Linux (AppImage, .deb y .rpm). En macOS el sistema solo deja instalar actualizaciones de apps firmadas, y el portable de Windows no tiene instalación que sustituir: ahí se mantiene Descargar, con la explicación. Si la descarga falla o no coincide con la publicada, no se instala nada.

En esta versión de PugIDE (macOS / portable) la actualización se instala a mano: «Descargar» abre la página de la versión con el archivo para tu sistema. Instálalo encima: se conservan tus proyectos.

PugIDE 0.14.0 está lista. Al reiniciar, el sistema te pedirá tu contraseña para instalar el paquete.
La pide Linux (pkexec), no PugIDE: los paquetes .deb y .rpm se instalan para todo el equipo. Con el AppImage no hace falta.
